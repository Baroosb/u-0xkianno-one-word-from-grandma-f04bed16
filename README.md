One word, 5 characters: "Robit" — the word a grandma would text about AI, spelling "robot" the way she would type it to a grandchild. The word lives in `entry.txt`; `main.py` copies it byte-for-byte to the output as `/output/entry.txt`. The word was picked by a candidate tournament judged pairwise against the published judge brief (see the build notes in the entry workspace).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
